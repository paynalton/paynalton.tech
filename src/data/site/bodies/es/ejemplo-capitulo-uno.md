## Primera sección

Este párrafo es material de prueba. <a id="origen-nota" href="#nota-uno">Consultar la nota</a>.

El recorrido de esta muestra comienza en una biblioteca, continúa en la ficha y llega hasta un capítulo. El texto permite observar cómo se comporta una lectura con varios párrafos, sin utilizar fragmentos de las obras que todavía no se han incorporado al sitio. Su propósito es probar la presentación y la navegación; no representa la voz ni las ideas del autor.

Una página de lectura debe conservar su continuidad cuando cambia el tamaño de letra. En una pantalla estrecha, las líneas se reorganizan y el contenido ocupa más altura. El índice y los enlaces siguen formando parte del documento, para que se pueda volver a un pasaje sin depender de una animación o de un servicio externo.


## Elementos de una lectura

Esta lista permite revisar el espacio entre elementos y el ajuste de líneas:

- Una idea breve, expresada en una sola línea cuando hay espacio suficiente.
- Un elemento más extenso, que necesita varias líneas en dispositivos pequeños y debe conservar una sangría cómoda para seguir leyendo.
- Un enlace al [segundo capítulo](../segunda-parte/), como ejemplo de continuidad entre páginas.

### Un pasaje de muestra

> Este bloque es una muestra tipográfica escrita para las pruebas. No es una cita de una persona ni de una obra publicada.

El énfasis puede aparecer en *cursiva* o con **una frase destacada**. También pueden mencionarse nombres largos, como una-palabra-de-prueba-extraordinariamente-larga-para-comprobar-el-ajuste, sin obligar a desplazar la página horizontalmente.

### Versos de prueba

La línea encuentra espacio,  
la siguiente busca lugar;  
son versos de una muestra,  
no una obra por publicar.
