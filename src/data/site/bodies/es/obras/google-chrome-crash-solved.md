Tras la última actualización de Ubuntu varias cosas dejaron de funcionar, todas ellas relacionadas con Dbus y Nvidia. Y no hablamos de pequeños procesos que nadie sabe para que sirven, sino del Centro de Software Ubuntu, Google Chrome, APT y bueno... supongo que los usuarios noveles estarán quejandose porque la solución no se puede realizar en forma gráfica.<br><br><br><br>Lo primero ha sido recuperar apt que terminaba su ejecución sin dar detalle alguno del error mas que una ligera entrada en el registro "Segment Fault \[Core\]". La solución: Actualización manual:<br><br>***\$sudo apt-get update***<br>***\$sudo apt-get upgrade***<br><br>Una vez terminado esto APT vuelve a funcionar, así como el Centro de Software Ubuntu.<br><br>A continuación nos queda actualizar el núcleo y limpiar los núcleos anteriores:<br><br>***\$sudo apt-get install linux-image-3.2.0-35-generic-pae***<br>***\$sudo apt-get autoremove***<br><br>Ahora, como todos los usuarios de Gentoo saben y al parecer los desarrolladores de Ubuntu no, cada actualización de núcleo requiere reinstalar los drivers privativos de Nvidia, pues los modulos se compilan específicamente para la versión de núcleo instalada en el sistema.<br><br>***\$sudo apt-get install --reinstall nvidia-current***<br><br>Reiniciamos para que los módulos de Nvidia se activen y corramos el nuevo núcleo.<br><br>***\$sudo reboot***<br><br>Una vez que el sistema se ha reiniciado nos resta reinstalar Google Chrome para que se registre en el nuevo sistema DBus y tome los nuevos módulos de Nvidia.<br><br>***\$sudo apt-get install --reinstall google-chrome-stable***<br><br>Con esto ya tendremos todo funcionando de nuevo...<br><br>A mi me llevó 2 horas entender y solucionar el problema, espero que esta guía les ahorre tiempo.
