Un sistema de juego RPG libre debiera ser capaz de permitir a los jugadores el interactuar con diferentes servidores, incluso con diferentes compañías.<br><br>Primero que nada es necesario un estándar de ficha de personaje cuyo propietario sea el usuario y este sea el responsable de su almacenamiento, de manera que pueda utilizar esta ficha de personaje en diferentes juegos sin grandes complicaciones.<br><br>De igual manera se debiera tener un estándar de comunicación cliente-servidor, npcs, objetos, mascotas, etc. Así se podrían tener diferentes clientes para un mismo juego, algunos libres, otros privativos, pero cada uno adaptado a las diferentes necesidades de los jugadores.<br><br>También podríamos tener un estándar de comunicación entre servidores de manera que un jugador pudiera transferir su personaje de un servidor a otro sin necesidad de desconectar el cliente, pudiendo ser transferencias transparentes (vas corriendo y sin darte cuenta pasas de un servidor a otro) o directas (teletransportación). Sería solo cuestión de compatibilidad entre sistemas la capacidad de poder transferir items, dinero, skills y mascotas de un servidor a otro.
