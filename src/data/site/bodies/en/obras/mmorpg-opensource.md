A free RPG game system should be able to allow players to interact with different servers, even with different companies.<br><br>First of all, there should be a character sheet standard whose owner is the user and who is responsible for its storage, so that the user can use this character sheet in different games without great complications.<br><br>Likewise, there should be a client-server communication standard, npcs, objects, pets, etc. This way, there could be different clients for the same game, some free, others proprietary, but each one adapted to the different needs of the players.<br><br>We could also have a server-to-server communication standard so that a player could transfer his character from one server to another without needing to disconnect the client, allowing for transparent transfers (you're running and without realizing it you switch from one server to another) or direct transfers (teleportation). It would be just a matter of system compatibility to have the ability to transfer items, money, skills and pets from one server to another.
