After the last Ubuntu update several things stopped working, all of them related to Dbus and Nvidia. And we're not talking about small processes that nobody knows the purpose of, but the Ubuntu Software Center, Google Chrome, APT and well... I suppose new users will be complaining because the solution can't be done graphically.<br><br><br><br>The first thing was to recover apt, which was ending its execution without giving any detail of the error other than a slight entry in the log "Segment Fault [Core]". The solution: Manual update:<br><br>***\$sudo apt-get update***<br>***\$sudo apt-get upgrade***<br><br>Once this is done, APT starts working again, as well as the Ubuntu Software Center.<br><br>Next, we need to update the kernel and clean up the previous kernels:<br><br>***\$sudo apt-get install linux-image-3.2.0-35-generic-pae***<br>***\$sudo apt-get autoremove***<br><br>Now, as all Gentoo users know and apparently the Ubuntu developers don't, each kernel update requires reinstalling the proprietary Nvidia drivers, since the modules are compiled specifically for the kernel version installed on the system.<br><br>***\$sudo apt-get install --reinstall nvidia-current***<br><br>Restart to activate the Nvidia modules and run the new kernel.<br><br>***\$sudo reboot***<br><br>Once the system has restarted, we need to reinstall Google Chrome so it registers in the new system DBus and uses the new Nvidia modules.<br><br>***\$sudo apt-get install --reinstall google-chrome-stable***<br><br>With this, everything should be working again...<br><br>It took me 2 hours to understand and solve the problem, I hope this guide saves you time.
