I've had this idea for a while to do continuous cultivation in endless bands within urban facilities.<br><br>The idea is to create a system that allows for continuous food production in stackable endless bands equipped with temperature, nutrition, and irrigation systems necessary for food production, enabling the construction of food-producing buildings, which would save a lot of space and even allow production to be brought into cities.<br><br>Yesterday I read a bit about the effect of LED lighting on plants, and today, upon reflecting on it, I came up with the idea of complementing the endless bands with individual per-plant control modules instead of equipment along the endless band.<br><br>These would be small vital support modules for plants, connected to a centralized controller, that could provide what is necessary for a plant to achieve its optimal development.<br><br>I'll start experimenting with beans (I love beans) to create a very simple module and see how well a plant can develop in one of these modules.<br><br>If it works well, I would like to create more modules and start producing food at home.<br><br>For now, it would only be with endogamous species, since I still don't have an idea on how to control pollination.
