I developed Yayauhqui with AI assistance to evaluate evidence of AWS infrastructure and identify possible security vulnerabilities. Its operation uses heuristic algorithms: it does not incorporate an AI model to perform the analysis. I have applied it to the review of infrastructure in a real work context.

I used this tool in work for Mead Johnson.

The distinction between how I built the tool and how it operates matters: AI assisted me during development, while assessments run through heuristics. This project documents experience reviewing AWS infrastructure evidence, without attributing the analysis conclusions to an AI model.
